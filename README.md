# Slide2HTML

把课程课件（PPT / PDF / 讲义）一键转成精美的双语交互式 HTML 学习页面。

## 它做什么

上传课程幻灯片、讲稿、大纲、作业要求等材料，自动生成一个**单文件、可离线打开**的 HTML 页面，包含：

- 📊 **仪表盘概览** — 课程信息、考核分布、重要日期一览
- 📝 **知识提炼** — 核心概念、定义、公式、方法、示例结构化展示
- ✅ **考核情报** — 作业 / 考试 / 项目要求拆解，评分权重校验
- 🔗 **知识关联** — 概念 ↔ 作业 ↔ 课程之间的双向映射
- 🔍 **客户端搜索** — 无需后端，打开即搜
- 🌐 **中英双语** — 自动切换，技术术语保留英文
- 📅 **时间线** — 合并所有材料中的截止日期与里程碑
- ⚠️ **冲突检测** — 材料之间矛盾的地方自动标出来供核实
- 📎 **来源可追溯** — 每条信息标注来自哪个文件第几页/第几张

## 快速使用

1. 把 `Slide2HTML` 文件夹放到你的 Doubao skills 目录下
2. 在对话中上传课件文件（PPT、PDF 均可，支持多文件）
3. 说一句："帮我把这些课件转成 HTML 学习页"
4. 得到一个 `slide2html.html` 文件，双击浏览器打开即可

## 项目结构

```
Slide2HTML/
├── SKILL.md                          # 主入口：角色定义 + 执行契约
└── references/
    ├── analysis-framework.md         # 分析层规则（§2–§25）
    ├── html-specification.md         # 产出层规则（§26–§51）
    └── quality-control.md            # 质检与交付规则（§52–§68）
```

## 设计原则

```
证据准确性 > 完整性 > 可追溯性 > 学术实用性
> 信息架构 > 前端体验 > 视觉美化
```

- **不编造**：材料里没有的信息明确标注"未找到"，绝不瞎编
- **单文件**：所有 CSS/JS 内联，无外部依赖，`file://` 直接打开
- **证据分级**：E1（原文）/ E2（多文件互证）/ E3（推断）/ E4（推测）
- **现代 UI**：对标 Linear / Notion 风格，干净克制，不是 2010 年代学术模板

## 生成效果

产出的 HTML 页面具备：

- 左侧导航 + 右侧内容的仪表盘布局
- 卡片式组件（概念卡、公式卡、资源卡、警告卡）
- 响应式设计（桌面 / 平板 / 手机）
- localStorage 学习进度标记
- 纯系统字体，无外部 CDN 依赖
